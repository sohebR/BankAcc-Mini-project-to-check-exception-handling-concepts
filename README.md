# Bank Account - Custom Exception Handling in Java

A simple Java mini project demonstrating **custom exception handling** using a basic bank account withdrawal scenario.

This project was developed as part of my **Java Full Stack training with Linkzie Tech**, under the guidance of **Mr. Ayan, Technical Trainer**.

---

## 📌 Project Overview

The program simulates a simple bank account where a customer attempts to withdraw money.

If the account has a zero balance, the program throws a custom exception called `ZeroBalance`, which is then handled using a `try-catch` block.

The project demonstrates how Java allows developers to create and handle **application-specific exceptions**.
